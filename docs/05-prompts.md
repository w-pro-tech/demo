# Prompts usados neste projeto

Registo dos pedidos feitos à IA, por ordem, para mais tarde se saber como cada parte foi construída.

## 1. Instruções do projeto (no chatbot)
> És o programador sénior da plataforma Loja Morabeza. Eu não sou programador: explica tudo em linguagem simples. Segue sempre o design system e os requisitos carregados. Dá-me o código completo, ficheiro a ficheiro, e diz onde o colar.

## 2. Plano
> Com base nos documentos do projeto, propõe as páginas do site, a estrutura de pastas e a ordem de construção. Usa só HTML, CSS e JavaScript. Não escrevas código ainda.

## 3. Estrutura base
> Cria a estrutura base: index.html, css/style.css com as variáveis do design system e js/produtos.js com 6 produtos de exemplo. Explica para que serve cada ficheiro.

## 4. Carrinho
> No projeto Loja Morabeza, cria js/carrinho.js com funções para adicionar, alterar a quantidade, remover e calcular o total. Guarda o carrinho no localStorage. Comenta cada função em português.

## 5. Checkout
> Cria a página checkout.html com resumo do carrinho, formulário (nome, telefone, morada e email), escolha de entrega e pagamento simulado. Valida os campos obrigatórios com mensagens claras. Não alteres os outros ficheiros. Dá o código completo e diz como testar.

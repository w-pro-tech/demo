# Requisitos: Loja Morabeza

## Requisitos funcionais
- **RF01:** O cliente vê o catálogo de produtos com nome, preço e categoria.
- **RF02:** O cliente filtra os produtos por categoria.
- **RF03:** O cliente abre a página de um produto e vê a descrição completa.
- **RF04:** O cliente adiciona produtos ao carrinho.
- **RF05:** O cliente altera quantidades e remove itens do carrinho.
- **RF06:** O sistema calcula o subtotal, a entrega e o total.
- **RF07:** O cliente preenche os dados de entrega e escolhe o pagamento.
- **RF08:** O sistema valida os campos obrigatórios antes de confirmar.
- **RF09:** O cliente vê uma confirmação com o número da encomenda.

## Requisitos não funcionais
- **RNF01:** O site funciona em telemóvel, tablet e computador.
- **RNF02:** Cada página carrega em menos de 2 segundos.
- **RNF03:** O carrinho mantém-se depois de atualizar a página.
- **RNF04:** O site segue o design system (cores, fontes e botões).
- **RNF05:** Os textos estão em português de Portugal.
- **RNF06:** O pagamento é simulado: nenhum dado de cartão é pedido nem guardado.
